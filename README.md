# Презентация для акимата Шымкента

Откройте `index.html` в любом современном браузере. Интернет и установка зависимостей не нужны.

- Презентация открывается в режиме одного раздела на всю высоту окна. Переход — кнопками, стрелками клавиатуры и PageUp/PageDown. Длинный раздел прокручивается внутри своего экрана. Escape или «Обычный просмотр» возвращает непрерывную страницу.
- «Сохранить в PDF»: открывает печать браузера; выберите сохранение в PDF. Для сохранения цветов включите фоновую графику.
- Калькулятор содержит условные цифры: это не коммерческое предложение и не подтверждённая экономия.

Компания: Airweb. Контактный сайт: https://airweb.kz/. До официальной подачи нужно подтвердить кейсы, состав команды, бюджет и условия проекта.

Airweb указан как компания по информации пользователя. Содержимое airweb.kz проверить не удалось; сведения о портфолио не добавлены.

Проверены синтаксис JavaScript, якоря HTML, расчёт экономии и удорожания, обработка пустых полей и границы навигации. Визуальная проверка в браузере не выполнена: доступные браузерные поверхности отсутствуют.
